# Balaji Balu — Aerospace Engineering Portfolio

Personal portfolio for aerospace manufacturing engineering, program execution, team leadership, continuous improvement and digital transformation.

## Live site

https://ijalabr.github.io/Balaji-Balu/

## About this site

- Static HTML, CSS and JavaScript; no framework, backend or paid dependency.
- Hosted on GitHub Pages.
- Includes original generated aerospace imagery. These are illustrative visuals, not photographs of company facilities or customer aircraft.
- Includes a downloadable copy of the resume supplied for this portfolio.

## Update the site

Edit `index.html`, `styles.css`, or `script.js`, and update the matching assets in `assets/`. The site is published from the repository's `master` branch root. Keep public descriptions sanitized and publish only approved material.
